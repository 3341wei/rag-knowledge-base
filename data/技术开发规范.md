# 星辰科技技术开发规范

## 一、代码规范

1. Python 代码需遵循 PEP 8 规范。
2. 所有函数需编写 docstring 说明用途和参数。
3. 提交代码前需通过单元测试。

## 二、Git 工作流

1. 主分支 master 只接受通过 code review 的合并请求。
2. 功能开发在 feature 分支进行，完成后提交 pull request。
3. 提交信息格式：类型: 描述，例如 feat: 新增登录接口。

## 三、接口规范

1. RESTful API 统一返回 JSON 格式。
2. 所有接口需包含错误码和错误信息。
3. 敏感数据传输必须使用 HTTPS。
